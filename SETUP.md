# Развёртывание на новой машине (машина клиента)

Пошагово для запуска сбора на чужом ПК. Windows, VSCode уже стоит.

## 1. Код

Разверни репозиторий (приватный) в удобную папку — например `C:\akg-agent-mode`.
Проще всего клонировать под своим доступом (`gh repo clone DIdro/akg-agent-mode`)
или распаковать архив.

## 2. Python + окружение

```powershell
cd C:\akg-agent-mode
python -m venv .venv
.venv\Scripts\python -m pip install playwright anthropic pytest
.venv\Scripts\python -m playwright install chromium
```

Проверка: `.venv\Scripts\python -m pytest tests\ -q` → все тесты зелёные.

## 3. Первичная настройка: браузер и кабинеты (интерактивно)

> Этот раздел выполняет Claude Code вместе с пользователем при первом
> развёртывании. Цель — определить рабочий браузер и записать реальные URL
> кабинетов клиента в `config_local.py`. Делать по шагам, не забегая вперёд.

1. **Открыть браузер** — проверить, что окружение (шаг 2) поднимает браузер:
   `.venv\Scripts\python -c "from playwright.sync_api import sync_playwright; p=sync_playwright().start(); b=p.chromium.launch(headless=False); b.new_page(); input('ok, закрой это окно вручную')"`.
   Если окно открылось — браузерная часть работает.

2. **Спросить у пользователя, какой браузер ходит в интернет БЕЗ VPN.**
   Российские соцсети (Дзен/ВК) могут не открываться из-за VPN или, наоборот,
   требовать VPN-обход. Задать прямой вопрос: «В каком браузере у вас Дзен, ВК
   и Тенчат открываются нормально — без танцев с VPN?» (обычно это Яндекс.Браузер
   или Chrome). Дождаться ответа.

3. **Открыть именно тот браузер, который назвал пользователь.**
   Найти путь к его `.exe` (типичные: Яндекс —
   `C:\Program Files\Yandex\YandexBrowser\Application\browser.exe`; Chrome —
   `C:\Program Files\Google\Chrome\Application\chrome.exe`; Edge —
   `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`). Прописать этот
   путь в `config_local.py` как `BROWSER_EXECUTABLE` (скопировать шаблон:
   `copy config_local.example.py config_local.py`). Браузер должен быть на
   движке Chromium (Яндекс/Chrome/Edge/Opera — да; Firefox — нет). Если
   пользователь не знает пути — найти файл поиском по диску.

4. **Попросить пользователя войти в Дзен, ВК и Тенчат.**
   Запустить `.venv\Scripts\python collect.py --login` — откроется указанный
   браузер (профиль агента) с тремя вкладками. Попросить пользователя в каждой
   **залогиниться в свой кабинет**: Дзен-Студия своего канала, ВК-сообщество
   (под админом), профиль Тенчата. Важно: аккаунт должен иметь **права
   редактора** Дзен-Студии и **админа** ВК-сообщества, иначе статистика не
   откроется. Пусть дойдёт в каждой вкладке до своего кабинета и НЕ закрывает
   окно, пока не скажешь.

5. **Сохранить адреса кабинетов в файл настройки.**
   Пока окно открыто (или попросив пользователя скопировать URL из адресной
   строки каждого кабинета), считать фактические адреса и записать в
   `config_local.py`:
   - `CHANNELS["dzen"]["public_url"]` — публичная страница Дзен-канала
     (`https://dzen.ru/<id-или-slug>`; из неё берётся publisherId);
   - `CHANNELS["vk"]["public_url"]` и `["screen_name"]` — сообщество
     (`https://vk.ru/<screen_name>`);
   - `CHANNELS["tenchat"]["public_url"]` — профиль клиента в Тенчате;
   - `LOGIN_TABS` — те же адреса (или страницы входа), чтобы повторный
     `--login` открывал сразу нужные кабинеты.
   После записи попросить пользователя закрыть окно браузера целиком. Сессии
   сохранятся в `profile/` (вне git), повторный логин не потребуется, пока они
   не протухнут.

## 4. API-ключ (только для ВК)

ВК распознаёт цифры со скриншотов через Claude API — процессу нужен ключ.
Дзен и Тенчат работают **без** ключа. Перед запуском В/полного сбора:

```powershell
$env:ANTHROPIC_API_KEY = "sk-ant-..."   # ключ Alex'а
```

(в этой же сессии PowerShell, из которой запускаешь `collect.py`).
Без ключа `--channels dzen,tenchat` соберётся, `vk` — упадёт на vision.

## 4b. Отправка в Реестр_факта (опционально)

Чтобы собранные данные попадали в клиентскую таблицу «Реестр_факта» → PDF,
задать вебхук нативного сервера и registry-имена каналов клиента:

```powershell
$env:AKG_WEBHOOK_URL = "https://n8n.crm-techno.ru/native/webhook/agent-metrics"
$env:AKG_WEBHOOK_KEY = "<SHARED_KEY из документа доступов>"
```

и в `config_local.py` прописать `registry`-имена под каналы клиента (см.
`config_local.example.py`): напр. `Корп. блог Дзен`, `Корп. ВК-сообщество`,
`Тенчат ЛБ` — дословно как в колонке «Канал (детальный)».

Тогда `collect.py --all` после сбора отправит строки на сервер; они
подмешиваются в `akg-report-rows`, замещая собственный сбор этих каналов, и
Apps Script пишет их в Реестр_факта. Серверная часть уже задеплоена
(см. `docs/server/DEPLOY.md`). Без вебхука сбор работает как раньше (только файлы).

⚠️ Слать в боевую таблицу только реальные клиентские кабинеты — данные с чужих
кабинетов под именами клиентских каналов загрязнят Реестр_факта.

## 5. Сбор

```powershell
.venv\Scripts\python collect.py --all
# или по одному:  .venv\Scripts\python collect.py --channels dzen
```

Результат — `out\<ISO-неделя>\<канал>.json` + скриншоты/xlsx. Смотри статус
(`ok` / `auth_required` / `failed`) и `needs_review` в JSON.

## Типичные проблемы

- **Дзен `auth_required` / редирект** — профиль залогинен не под аккаунтом с
  доступом в Студию. Перелогинься в окне (`--login`) под нужным Яндекс-аккаунтом.
- **ВК «Не удалось загрузить данные»** — дашборд грузится ~8с, баннер на старте
  транзиентный (код ждёт). Если держится — проверь, что залогинен админ
  сообщества и вручную в браузере дашборд открывается.
- **ВК падает на vision** — не задан `ANTHROPIC_API_KEY` (шаг 4).
- **Период в ВК/Тенчате «7 дней», не отчётная неделя** — известное ограничение
  (`needs_review=true`), значения реальные за показанный период.
