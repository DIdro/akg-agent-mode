## Структура XLSX (сверено на выгрузке 2026-07-23)
Строки: `[0]` название («Статьи/Посты канала "..."»), `[1]` шапка, `[2]` «Всего» (метрики сдвинуты: начинаются с col1, а не col4), `[3:]` публикации.
Колонки публикации (row 3+):
| idx | поле |
|---|---|
| 0 | Дата публикации (excel serial) |
| 1 | Тип публикации |
| 2 | Публикация (заголовок, часто пустой) |
| 3 | Ссылка на публикацию |
| 4 | Дочитывания и просмотры (reads) |
| 5 | Показы (shows) |
| 6 | Открытия (opens) |
| 7 | Время просмотра в мин |
| 8 | Комментарии |
| 9 | Подписки |
| 10 | Лайки |
| 11 | Стеллы |

Два типа выгрузки: `article` (статьи) + `brief` (посты) — суммируем оба. Итог берём суммой строк `[3:]` (строку «Всего» не парсим из-за её сдвига).
