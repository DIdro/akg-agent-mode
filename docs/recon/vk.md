## Идентификаторы

## Актуальный дашборд статистики (то, что использовать)
URL: `https://vk.ru/groups/dashboard/@nppsatek?sectionId=<section>&subsectionId=<subsection>`

Секции (`statsDashboard.getDashboardSections`):
| sectionId | Вкладка UI | Подсекции |
|---|---|---|
| `top_community` | Сообщество | `stat_board_general` (Общее), `stat_board_audience` (Аудитория), `stat_board_content` (Контент) |
| `top_posts` | Посты | general / audience / content |
| `top_stories` | Истории | general / audience / active / narratives / ended |
| `top_clips` | Клипы | general / audience / content |
| `top_video` | Видео | general / audience / content |

**Нет отдельной вкладки «Канал»** (VK Видео-канал) — у nppsatek её не оказалось; в клиентском agcapital она есть. У Alex'а «ВК блог» = вкладка «Канал» протестировать нельзя.

## Метрики на «Сообщество → Общее» (за выбранный период)
Посещения, **Просмотры контента**, **Охват контента**, Подписчики, Подписки на уведомления, Переходы по кнопке действия. + графики «Охват и просмотры по типу контента», «Количество подписчиков».
Селектор периода в шапке (по умолчанию `last7Days`; календарь, разрешён диапазон от ~окт-2023).

## Способы съёма (по убыванию надёжности)
1. **Встроенный экспорт** — иконка download в шапке дашборда. `exportConfig.exportFormats` = **xls, csv**. Это лучший путь (точные числа, как XLSX-экспорт Дзена у Маши). Требует довести клик экспорта → скачивание файла до конца (разведать диалог экспорта — какой скоуп/формат отдаёт).
2. **Скриншот + vision** по вкладкам — цифры на экране читаемы, надёжный фолбэк.
3. XHR JSON `statsDashboard.getOwnerStats` — **асинхронный**: возвращает `task_id`, данные тянутся отдельным поллингом. Сложнее экспорта и скринов, не рекомендуется.

## Вывод
ВК — полноценный тестовый кабинет. Рекомендация для vk.py: экспорт XLS как основной путь + скриншоты вкладок для сверки. Скриншоты видел: Посещения 5, Просмотры контента 28, Охват контента 5, Подписчики 0 (период 17.07–23.07).
