# АКГ: агентский режим сбора маркетинг-статистики

Playwright-автоматизация съёма статистики из личных кабинетов Дзен / ВК / Тенчат
для маркетинг-отчёта АКГ «Капитал» — замена ручных скриншотов.

Дизайн: [docs/superpowers/specs/2026-07-23-akg-agent-mode-design.md](docs/superpowers/specs/2026-07-23-akg-agent-mode-design.md)
Разведка кабинетов: [docs/recon/](docs/recon/) (dzen / vk / tenchat).

## Запуск

```
python collect.py --login                      # разовый ручной логин в кабинеты
python collect.py --all                        # все каналы за последнюю завершённую ISO-неделю
python collect.py --channels dzen,vk --week 2026-W30
```

Браузер — **Яндекс.Браузер** (в обход Amnezia VPN, путь в `config.BROWSER_EXECUTABLE`),
всегда видимое окно (headed). Профиль изолированный: `profile/` в репо — личный
браузер не затрагивается. `profile/` (живые сессии) и `out/` (результаты) — вне git.

Результат: `out/<ISO-week>/<channel>.json` + скриншоты/xlsx. Никуда не отправляется.

## Что собирается по каналам

| Канал | Способ | Метрики |
|---|---|---|
| **Дзен** | экспорт XLSX из Студии (`source=xlsx`) | по постам + итог: дочитывания, показы, открытия, время, комментарии, подписки, лайки; + подписчики канала |
| **ВК** | вкладки дашборда `groups/dashboard/@<screen>` → скриншот + распознавание (`source=vision`) | Охват контента, Просмотры контента, Посещения, Подписчики, Охват постов, Просмотры видео. Вкладки «Канал» у теста (nppsatek) нет → `channel_views=null` |
| **Тенчат** | клик кнопки статистики → перехват JSON `account/stats` (`source=xhr`) | Охват записей, Просмотры, Подписчики (фиксированный период «7 дней») |

`status`: `ok` / `auth_required` (истекла сессия → `--login`) / `failed`.
`needs_review=true` — распознанное число под сомнением, частичный сбор или период не совпал с отчётной неделей.

## ⚠️ Условия доступа (важно при переносе)

- **Дзен-Студия** доступна только под аккаунтом с правами редактора канала и только в headed-режиме
  (headless редиректит на публичную страницу). Профиль агента логинить под нужным Яндекс-аккаунтом.
- **ВК** самоподдерживающе банит за частые заходы (`error_code 6`, «Не удалось загрузить данные»).
  Не гонять сбор в цикле — один заход на прогон.
- **Тенчат**: у пустого профиля значения нули; маппинг `reach`/`views` из JSON выведен по именам полей,
  сверить на профиле с реальной активностью.

## Статус теста

Прогон-1 (2026-07-23, неделя W29): **Дзен ok** (реальные цифры), **Тенчат ok** (механика, нули на пустом
профиле). **ВК** — код корректен, но кабинет временно в rate-limit ВК после отладочных прогонов;
перепроверить одним заходом после паузы.

Осталось: прогон-2 через 1–2 дня без `--login` — проверка гипотезы «живой профиль лечит протухание
сессий» (и заодно чистый прогон ВК, когда бан спадёт).
